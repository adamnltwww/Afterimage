# 0.9.6 — 开屏与主轴共用同一画面

移除 0.9.5 的独立开屏丝线、横向缩放和局部裁切。开场直接显示真实主轴，横贯屏幕两端，弯曲、散开的纤维逐渐聚拢；只改变纤维曲线，不拉粗笔触。主轴画布始终保留，不再在结束时替换成另一幅画面。

AFTERIMAGE 先出现，放大约三成，并有一次柔和金光掠过；约 0.4 秒后散丝浮现。字标保留从丝线上方移动到顶部的动作，上移时逐渐恢复正式字标的尺寸与光泽。实际标题、主轴、浮层统一测量窗口坐标，避免 SwiftUI 导航栏不同托管坐标导致错位。落点后与正式字标同步淡入淡出。

自动完成与跳过共用结尾：细丝用约 0.85 秒收束到正常形态，随后按钮、字标、文字、照片与主题细丝用 1.15 秒同步淡入。按钮的整块玻璃材质一起淡入，而非只改变图标。界面元素预先参与布局，淡入不会改变主轴高度。

跳过省略开场停留，保留相同的收束和淡入。后台进入时结束开屏，不在恢复后重播；减少动态效果时保留短淡入。空资料页同样有全宽丝线，再渐淡为背景。

新增像素检查：开场丝线覆盖整个视口；结束开屏前后像素一致，并与普通主轴画面一致。继续检查自动结束、跳过后新建、后台恢复，以及主轴两端、弹层和操作布局。
